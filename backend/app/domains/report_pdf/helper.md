# MedSync PDF Reports — Frontend Integration Guide

This guide describes how frontend applications (React, Next.js, Vue, Angular, etc.) should authenticate, query, and trigger file downloads for official PDF reports generated by the MedSync backend.

---

## 1. Base URL & Protocol

- **Base Endpoint:** `/api/v1/reports/pdf`
- **Method:** `GET`
- **Response Media Type:** `application/pdf`
- **Download Header:** `Content-Disposition: attachment; filename="<report_name>_<timestamp>.pdf"`
- **Cache Strategy:** `Cache-Control: no-cache, no-store, must-revalidate`

---

## 2. Authentication & RBAC Rules

All requests must supply the user's JWT access token in the `Authorization` header:

```http
Authorization: Bearer <access_token>
```

### Role Matrix

| Endpoint | Permitted Roles | Notes |
|---|---|---|
| `GET /api/v1/reports/pdf/appointments-summary` | `Admin`, `Branch Manager` | Doctor & Receptionist: `403 Forbidden` |
| `GET /api/v1/reports/pdf/doctor-revenue` | `Admin`, `Branch Manager` | Doctor & Receptionist: `403 Forbidden` |
| `GET /api/v1/reports/pdf/outstanding-balances` | `Admin`, `Branch Manager`, `Receptionist` | Receptionist **must** pass `patient_id` |
| `GET /api/v1/reports/pdf/treatment-frequency` | `Admin`, `Branch Manager` | Doctor & Receptionist: `403 Forbidden` |
| `GET /api/v1/reports/pdf/insurance-summary` | `Admin`, `Branch Manager` | Doctor & Receptionist: `403 Forbidden` |

### Branch Scoping & Ownership Rules

1. **Admin:**
   - Can query across all branches (`branch_id` omitted/null) to get a consolidated enterprise report.
   - Or filter by a specific branch (`?branch_id=2`).
2. **Branch Manager:**
   - Automatically scoped to their assigned `branch_id`.
   - If `branch_id` is omitted, the backend defaults to the manager's assigned branch.
   - If a Branch Manager supplies a `branch_id` that does **not** match their own branch, the API responds with `403 Forbidden`.
   - If a Branch Manager has no branch assigned, the API responds with `403 Forbidden`.
3. **Receptionist:**
   - Only permitted to access `GET /api/v1/reports/pdf/outstanding-balances`.
   - **Must** provide `patient_id` (e.g. `?patient_id=12`). Aggregate clinic-wide balance exports return `422 Unprocessable Content`.

## 3. Endpoints Specification

### 1. Appointments Summary Report
* **Route:** `GET /api/v1/reports/pdf/appointments-summary`
* **Orientation:** Portrait
* **Purpose:** Daily breakdown of scheduled, completed, cancelled, and total appointments with totals.
* **Query Parameters:**

| Parameter | Type | Required? | Description |
|---|---|---|---|
| `branch_id` | `integer` (gt 0) | Optional | Branch ID filter (Admin only; Branch Manager defaults to own branch) |
| `from` | `string` (YYYY-MM-DD) | Optional | Start of date range (must be `<= to`) |
| `to` | `string` (YYYY-MM-DD) | Optional | End of date range (must be `>= from`) |

* **Example Request:**
  ```http
  GET /api/v1/reports/pdf/appointments-summary?from=2026-01-01&to=2026-01-31 HTTP/1.1
  Authorization: Bearer <token>
  ```

---

### 2. Doctor Revenue & Productivity Report
* **Route:** `GET /api/v1/reports/pdf/doctor-revenue`
* **Orientation:** Portrait
* **Purpose:** Ranked list of doctor earnings, appointment volume, and total revenue.
* **Query Parameters:**

| Parameter | Type | Required? | Description |
|---|---|---|---|
| `branch_id` | `integer` (gt 0) | Optional | Branch ID filter |
| `from` | `string` (YYYY-MM-DD) | Optional | Start date for billing period |
| `to` | `string` (YYYY-MM-DD) | Optional | End date for billing period |

* **Example Request:**
  ```http
  GET /api/v1/reports/pdf/doctor-revenue?branch_id=1&from=2026-01-01&to=2026-03-31 HTTP/1.1
  Authorization: Bearer <token>
  ```

### 3. Outstanding Balances & Aging Ledger
* **Route:** `GET /api/v1/reports/pdf/outstanding-balances`
* **Orientation:** Landscape (wide table format)
* **Purpose:** Detailed invoice ledger showing patient dues, payable amount, amount paid, and outstanding balances.
* **Query Parameters:**

| Parameter | Type | Required? | Description |
|---|---|---|---|
| `branch_id` | `integer` (gt 0) | Optional | Branch filter |
| `patient_id` | `integer` (gt 0) | **Conditional** | **Mandatory for Receptionist**; Optional for Admin & Branch Manager |

* **Example Request (Admin/Branch Manager - Full Clinic Ledger):**
  ```http
  GET /api/v1/reports/pdf/outstanding-balances HTTP/1.1
  Authorization: Bearer <token>
  ```
* **Example Request (Receptionist - Patient-Specific Ledger):**
  ```http
  GET /api/v1/reports/pdf/outstanding-balances?patient_id=42 HTTP/1.1
  Authorization: Bearer <token>
  ```

### 4. Treatment & Service Utilization Report
* **Route:** `GET /api/v1/reports/pdf/treatment-frequency`
* **Orientation:** Portrait
* **Purpose:** Frequency and volume of treatments/procedures administered.
* **Query Parameters:**

| Parameter | Type | Required? | Description |
|---|---|---|---|
| `branch_id` | `integer` (gt 0) | Optional | Branch filter |
| `category` | `string` (1–50 chars) | Optional | Filter by catalogue category (e.g. `Orthodontics`, `Preventative`) |
| `from` | `string` (YYYY-MM-DD) | Optional | Start date of appointment range |
| `to` | `string` (YYYY-MM-DD) | Optional | End date of appointment range |

* **Example Request:**
  ```http
  GET /api/v1/reports/pdf/treatment-frequency?category=Preventative&from=2026-01-01&to=2026-06-30 HTTP/1.1
  Authorization: Bearer <token>
  ```

## 4. Frontend Code Snippets

### A. Generic Download Utility (Axios / Fetch)

Because PDF endpoints return binary streams (`application/pdf`), ensure you configure `responseType: 'blob'`.

```typescript
// reportService.ts
import axios from 'axios';

interface DownloadReportParams {
  endpoint: string;
  params?: Record<string, any>;
  defaultFilename?: string;
}

export async function downloadPdfReport({
  endpoint,
  params = {},
  defaultFilename = 'report.pdf',
}: DownloadReportParams): Promise<void> {
  const token = localStorage.getItem('access_token');

  try {
    const response = await axios.get(`/api/v1/reports/pdf/${endpoint}`, {
      params,
      responseType: 'blob',
      headers: {
        Authorization: `Bearer ${token}`,
      },
    });

    // 1. Extract filename from Content-Disposition header if provided
    let filename = defaultFilename;
    const disposition = response.headers['content-disposition'];
    if (disposition && disposition.includes('filename=')) {
      const match = disposition.match(/filename=["']?([^"';]+)["']?/);
      if (match && match[1]) {
        filename = match[1];
      }
    }

    // 2. Create in-memory Blob URL
    const blob = new Blob([response.data], { type: 'application/pdf' });
    const url = window.URL.createObjectURL(blob);

    // 3. Trigger immediate browser download
    const link = document.createElement('a');
    link.href = url;
    link.setAttribute('download', filename);
    document.body.appendChild(link);
    link.click();

    // 4. Cleanup
    link.parentNode?.removeChild(link);
    window.URL.revokeObjectURL(url);
  } catch (error: any) {
    // If the error response is a blob, decode the JSON error message
    if (error.response?.data instanceof Blob) {
      const text = await error.response.data.text();
      try {
        const errorJson = JSON.parse(text);
        throw new Error(errorJson.detail || 'Failed to download report');
      } catch {
        throw new Error('Failed to download report');
      }
    }
    throw error;
  }
}
```

### B. React Export Button Example

```tsx
// ExportReportButton.tsx
import React, { useState } from 'react';
import { downloadPdfReport } from './reportService';

export const ExportAppointmentsButton: React.FC<{ fromDate?: string; toDate?: string }> = ({
  fromDate,
  toDate,
}) => {
  const [loading, setLoading] = useState(false);

  const handleExport = async () => {
    setLoading(true);
    try {
      await downloadPdfReport({
        endpoint: 'appointments-summary',
        params: {
          from: fromDate,
          to: toDate,
        },
        defaultFilename: 'appointments_summary.pdf',
      });
    } catch (err: any) {
      alert(err.message || 'Error downloading PDF');
    } finally {
      setLoading(false);
    }
  };

  return (
    <button onClick={handleExport} disabled={loading} className="btn-export-pdf">
      {loading ? 'Generating PDF...' : 'Export PDF'}
    </button>
  );
};
```

## 5. HTTP Error Handling & Status Codes

| Status Code | Reason | Meaning / Resolution for Frontend |
|---|---|---|
| `200 OK` | Success | Returns the binary PDF stream. |
| `401 Unauthorized` | Invalid / Expired Token | Redirect user to `/login`. |
| `403 Forbidden` | Insufficient Permissions | User does not have the required role (e.g. Doctor), or Branch Manager requested another branch. |
| `422 Unprocessable Content` | Validation Failure | Check parameters: <br>&bull; `from` is after `to` (`from must be on or before to`).<br>&bull; Receptionist omitted `patient_id` on outstanding balances (`Receptionists must provide patient_id`). |
| `500 Internal Server Error` | Backend Server Error | Display general error notification. |
